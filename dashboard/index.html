How the board is priced

The board separates the snapshot three ways before it ranks anything: protocols whose token already trades are the comparables, never the ranked; wrapped, staked, bridged and exchange products of a traded token are set aside; the rest — every watchlist protocol among them — are priced by the curve. Bands come from a seeded bootstrap that refits the curve on resampled comparables (seed 20261114, 240 rounds): they state the model's uncertainty, and each verdict nets a farmer's expected share against the band's low end, never the headline value.
